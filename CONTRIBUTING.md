# Contributing

Keep the core independent of any employer, tenant, project, or connector implementation. Submit fictional reproductions and explain the behavior being improved. Never include real project records, private messages, credentials or operational receipts.

Preserve native controls and task constraints. Prefer a focused skill/reference change over adding the same rule everywhere. Run the offline validator and deterministic packaging, then identify which behavioral scenarios need rechecking in a hosted agent. Describe observed results separately from expected results.

Bump the version for a release. Do not change personal deployment configuration or claim live validation from offline checks.
